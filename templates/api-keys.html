📚 Quick Start Guide

1. Initialize Session

Gunakan API key Anda untuk membuat session baru: 

POST /auth/initialize
Content-Type: application/json

{
  "api_key": "YOUR_API_KEY",
  "timestamp": 1234567890,
  "signature": "your_signature_here"
}

2. Connect to Socket.IO

Gunakan session ID untuk connect ke Socket.IO: 

const socket = io("http://localhost:8000", {
  auth: {
    session_id: "YOUR_SESSION_ID"
  }
});

socket.on("connected", (data) => {
  console.log("Connected:", data);
});

3. Send Audio for Processing

Upload audio untuk mendapatkan navigation response: 

POST /conversation/{session_id}
Content-Type: multipart/form-data

{
  "audio": [audio_file],
  "screen_name": "home_screen"
}
