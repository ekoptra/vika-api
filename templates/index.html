Integrasi Mudah dengan JKN Mobile

3 langkah mudah mengintegrasikan Vika SDK ke aplikasi JKN Mobile

1

Dapatkan API Key

Daftar dan dapatkan API key secara instant. Gratis untuk 1000 request pertama setiap bulan.

API_KEY="vika_xxx..."
2

Add Dependency

Tambahkan dependency ke build.gradle.kts project Android Anda.

implementation("com.vika.sdk:vika-sdk:1.0.1")
3

Initialize & Use

Initialize SDK dan buka voice UI untuk pengguna JKN.

VikaSDK.getInstance().openVikaSDK()
MainActivity.kt 
// 1. Initialize SDK
val config = SDKConfig.Builder("YOUR_API_KEY")
    .debugMode(BuildConfig.DEBUG)
    .allowedDeepLinkSchemes("jkn")
    .build()

VikaSDK.initialize(this, config) { /* Ready */ }

// 2. Register screens
VikaSDK.getInstance().registerScreens(listOf(
    ScreenRegistration(
        screenId = "pendaftaran",
        screenName = "Pendaftaran",
        deepLink = "jkn://pendaftaran",
        navigationType = NavigationType.DeepLink("jkn://pendaftaran")
    )
))

// 3. Open Voice UI
VikaSDK.getInstance().openVikaSDK(context)

Fitur Unggulan

Teknologi terdepan untuk pengalaman voice navigation yang luar biasa

Voice Recognition AI

Dukungan multibahasa yang membuat pengguna JKN dapat berinteraksi dengan mudah

Real-time Processing

Response time yang cepat melalui WebSocket. Pengalaman real-time yang responsif untuk pengguna JKN.

Enterprise Security

HMAC signature verification, API key authentication, dan enkripsi end-to-end untuk data sensitif JKN.

JKN Mobile Ready

Dioptimalkan khusus untuk JKN Mobile Android. SDK native Kotlin yang lightweight dengan deep link navigation dan Jetpack Compose UI.

PII Data Masking

Hasil speech-to-text dan deeplink otomatis di-masking PII-nya sebelum dikirim ke LLM. Menjamin data sensitif peserta BPJS tetap aman dan terlindungi.
